🎯 Guess The Number

A modern and interactive Guess The Number game built using HTML, CSS, and JavaScript. The player has to guess a randomly generated number between 1 and 50 while trying to achieve the highest possible score. The project focuses on DOM manipulation, game logic, responsive design, animations, and Local Storage.

✨ Features
🎲 Random number generation (1–50)
🎚️ Difficulty Levels (Easy, Medium, Hard)
🏆 Score & Best Score system
💾 Best Score saved using Local Storage
🌙 Dark Mode
📱 Fully Responsive Design
🎵 Sound Effects
✨ Smooth Animations
⌨️ Press Enter to submit guesses
🔄 Play Again functionality
🎉 Winning celebration
🛠️ Technologies Used
> HTML5
> CSS3
> JavaScript (ES6)
📚 Concepts Practiced
1. DOM Manipulation
2. Event Listeners
3. Conditional Statements
4. Variables & Functions
5. Random Number Generation
6. Local Storage
7. CSS Animations
8. Responsive Web Design
